# Propty brand assets

`originals/propty-standalone.jpg` is the user-supplied standalone Propty logo.
`originals/propty-jcx-venture.png` preserves the supplied full-resolution combined artwork.

The website uses `web/public/brand/propty.jpg` and `web/public/brand/jcx.png` through the shared Brand component. The standalone artwork is framed using CSS without changing its lettering or proportions. JCX is displayed separately with “Powered by”.

Do not replace these assets with generated or reconstructed logos. Older assets in `web/public/propty` remain for compatibility with existing references and provenance.
