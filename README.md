# JCX Global PropTech Intelligence Atlas

A source-backed research experience mapping global property technology, leading real-estate operators, measurable outcomes, startup ecosystems, standards, failure lessons, and the practical questions a developer in Bangladesh should ask next.

The web application lives in `web/`. The research corpus and its validation artifacts live in `data/`, `research/`, and the root analysis documents.

## Local development

```bash
cd web
npm install
npm run dev
```

## Release checks

```bash
cd web
npm run typecheck
npm run build
```

The public website is an informational research product. A listing is not a procurement endorsement, investment recommendation, or guaranteed forecast.
